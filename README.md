# Future Now Hub (prototype)

A clickable prototype of a hub that takes a Future Now challenge from first idea to
brief, module, showcase, and student and staff records.

**Every organisation, person, module and figure in it is invented.** It is not a live
University system and holds no real data. Anything a visitor changes is kept only in
their own browser.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole prototype in one file. GitHub Pages shows it as the home page. |
| `favicon.png` | The small icon shown in the browser tab. |
| `README.md` | This note. |

## Publishing with GitHub Pages

1. In the repository, choose **Add file > Upload files** and drag in `index.html` and
   `favicon.png` (and this README if you like). Choose **Commit changes**.
2. Go to **Settings > Pages**. Under **Build and deployment**, set **Source** to
   **Deploy from a branch**, then choose the **main** branch and the **/ (root)** folder.
   Choose **Save**.
3. After a minute or two the address appears at the top of the Pages settings. It will
   look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

On a free GitHub account, Pages only works when the repository is **public**. A
GitHub Pages site can be opened by anyone who has the address.

## Updating

Upload a new `index.html` with the same name and commit it. The site updates within a
few minutes. If you still see the old version, refresh the page.

## Notes

- The page asks search engines not to list it, because it is a prototype.
- The **Reset demo data** button restores the original sample data in your browser.
